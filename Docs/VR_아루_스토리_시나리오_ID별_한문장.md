# VR 단편 시나리오 — 다음 약속은 의뢰가 아니야

## ID별 한 문장 버전

- 한 ID에는 한 문장만 배치한다.
- 내레이션과 전화 상대는 입모양을 사용하지 않는다.
- 아루의 대사는 기본적으로 입모양을 사용한다.
- 선택지 분기 이후에는 `nextIndexOverride`로 공통 구간에 합류한다.

## 분기 연결 요약

```text
0 → 1 → … → 9
               ├─ 선택 A-1: 10 → 11 ─┐
               └─ 선택 A-2: 12 → 15 ─┴→ 16 → … → 38
                                                  ├─ 선택 B-1: 39 → 42 ─┐
                                                  └─ 선택 B-2: 43 → 47 ─┴→ 48 → … → 56
```

## `nextIndexOverride` 설정

| ID | 값 | 이유 |
|---:|---:|---|
| 11 | 16 | 선택지 A-1 종료 후 공통 전화 장면으로 이동 |
| 15 | 16 | 선택지 A-2 종료 후 공통 전화 장면으로 이동 |
| 42 | 48 | 선택지 B-1 종료 후 공통 작별 장면으로 이동 |
| 47 | 48 | 선택지 B-2 종료 후 공통 작별 장면으로 이동 |

나머지 대사는 `nextIndexOverride = -1`로 설정하여 다음 ID로 순차 진행한다.
